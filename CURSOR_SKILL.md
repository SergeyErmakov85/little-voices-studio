# Cursor Skill — Hanen Speech Platform Development

## PROJECT CONTEXT

You are developing a therapeutic speech-development web application for toddlers aged 2.5–4 years.

The system combines:
- Hanen methodology,
- parent coaching,
- real-world toys,
- digital interaction,
- emotional engagement,
- communication-centered therapy.

The product is a hybrid between:
- therapeutic platform,
- magical interactive world,
- parent assistant,
- communication development system.

---

# DESIGN PRINCIPLES

## The app should feel like:
- Pixar world,
- magical cozy room,
- emotional interactive story,
- warm fantasy environment.

## The app should NOT feel like:
- school,
- SaaS dashboard,
- educational testing app,
- ABA drill platform.

---

# CORE DEVELOPMENT PRIORITIES

Priority order:
1. emotional safety,
2. responsiveness,
3. communication support,
4. parent-child interaction,
5. speech stimulation,
6. visual beauty,
7. performance.

---

# UI RULES

## CHILD UI

Requirements:
- large touch zones,
- minimal text,
- smooth animations,
- soft glowing gradients,
- calm pacing,
- magical interactions,
- emotional feedback.

Avoid:
- clutter,
- dense UI,
- tiny controls,
- overstimulation,
- rapid transitions.

---

## ADULT UI

Requirements:
- coaching panels,
- step-by-step guidance,
- OWL reminders,
- 4S prompts,
- progress tracking,
- interaction analytics.

---

# HANEN IMPLEMENTATION RULES

## OWL
The interface should support:
- Observe
- Wait
- Listen

This means:
- intentional pauses,
- interaction timing,
- reduced verbal overload.

---

## 4S
The app should reinforce:
- Say Less
- Stress
- Go Slow
- Show

The UI and generated prompts must follow these rules.

---

# GAME DESIGN RULES

Every mini-game must:
- support communication,
- encourage turn-taking,
- create communication temptations,
- synchronize with physical toys,
- emotionally reward interaction attempts.

Never optimize games around:
- correctness,
- speed,
- competition,
- scoring.

---

# REAL-WORLD TOY MAPPING

## Stacking Cups
Targets:
- sequencing,
- spatial language,
- anticipation,
- “up/down/fall”.

---

## Pounding Toy
Targets:
- imitation,
- rhythm,
- cause-effect,
- sound imitation:
  - boom,
  - bam,
  - knock.

---

## Magnetic Fishing
Targets:
- requesting,
- turn-taking,
- pointing,
- waiting,
- “more”, “give”, “fish”.

---

## Sorting Games
Targets:
- categories,
- receptive language,
- color vocabulary,
- following instructions.

---

## Memory Games
Targets:
- shared attention,
- emotional engagement,
- auditory memory,
- interaction pacing.

---

## Threading Toys
Targets:
- bilateral coordination,
- fine motor planning,
- patience,
- cooperative interaction.

---

# ANIMATION STYLE

Use:
- Framer Motion,
- soft easing,
- ambient glow,
- floating particles,
- layered transitions,
- subtle bounce physics.

Avoid:
- harsh easing,
- flashing effects,
- arcade-style movement.

---

# PERFORMANCE RULES

The platform must:
- work smoothly on tablets,
- support low-end devices,
- optimize animations,
- lazy-load heavy assets,
- maintain responsive touch input.

---

# ARCHITECTURE

Recommended structure:
- app/
- features/
- shared/
- entities/
- widgets/
- pages/

Use:
- modular feature architecture,
- reusable game engines,
- configurable lesson systems.

---

# AI FEATURES

Potential AI modules:
- parent interaction analysis,
- OWL coaching,
- speech-stage adaptation,
- routine generation,
- progress summaries,
- therapy recommendations.

---

# FINAL PRODUCT GOAL

The system should become:
- a full-scale speech-development ecosystem,
- a parent coaching assistant,
- a magical child experience,
- a scalable therapeutic platform.

The platform should emotionally transform parent-child communication rather than simply teaching vocabulary.
